Mid-price Import Discharge And Export Priority Implementation Plan

中間単価でも買電中は放電優先にする制御と、売電時の Pro3 / DELTA 3 Max Plus / DELTA 3 Plus 2 優先充電順を整理する計画。

Goal

中間単価でも買電中は、DELTA Pro 3 が十分な残量を持つ場合にバッテリー放電を優先する。売電時は既存の優先順位制御に沿って、どの機器へ充電するかを理由文とテストで固定する。

Target Behavior

  • 低単価ではない買電中は self-powered-discharge を優先する。
  • 低単価中は従来どおり深夜充電・不足補充を許可する。
  • 料金コンテキストがない場合は無条件に放電へ切り替えない。
  • 売電時は原則 DELTA Pro 3 を先に余剰吸収させる。
  • DELTA 3 系 write target の優先度が Pro3 より高い場合のみ Pro3 待ちを bypass する。

Safety Boundaries

  • 既存の実機 write gate と最小コマンド間隔を維持する。
  • reserve は minimum reserve / min discharge reserve を下回らない。
  • self-powered-discharge は night plan owner のままとし、surplus plan との競合を避ける。

Implementation Steps

  1. 高単価専用 helper を低単価以外の料金帯 helper へ置き換える。
  2. 中間単価買電中にも SelfPowered discharge 候補を出す。
  3. surplus recovery でも中間単価買電中の TOU 復帰を抑制する。
  4. DELTA 3 系の WAIT_PRO3 理由を優先順が分かる文言に更新する。
  5. night / surplus / auxiliary battery planner の単体テストを追加する。
  6. backend tests、diff check、review loop を実行する。
