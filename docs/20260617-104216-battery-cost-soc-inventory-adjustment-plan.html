Battery Cost SOC Inventory Adjustment Plan

作成日時: 2026-06-17 10:42:16 JST

目的

料金比較にSOC増減による在庫価値を追加し、生の削減額と在庫調整後削減額を分けて表示する。制御や実機writeは変更しない。

背景

現行の推定損失は batteryInputKWh - batteryOutputKWh を中心に見ているため、日をまたいで残ったSOCが損失のように見える場合がある。前日以前から貯めたSOCを使った日は、逆に当日の効果を過大評価する場合がある。

実装範囲

API
在庫SOC、在庫kWh、在庫価値、調整後削減額を追加する。
集計
power_logs.battery_soc と機器容量から日別SOC増減を評価する。
UI
サマリーと日別テーブルに在庫補正を表示する。
安全境界
EcoFlow/Natureへのwrite、制御判断、実機制御フラグは変更しない。

計算式

inventoryDeltaKWh = capacityKWh * (endSoc - startSoc) / 100
inventoryValueRateYen = 対象日の料金マスタの最高買電単価
inventoryValueYen = inventoryDeltaKWh * inventoryValueRateYen
adjustedEstimatedSavingsYen = estimatedSavingsYen + inventoryValueYen

テスト

  • SOCが上がった日は在庫価値がプラスになり、調整後削減額が生の削減額より大きくなる。
  • SOCが下がった日は在庫価値がマイナスになり、過去在庫消費として補正される。
  • SOCまたは容量が不足している場合も既存比較は返る。
